# 🧠 Quiz Application

A Java-based Quiz Application developed as an academic project to demonstrate object-oriented programming concepts, user interaction, timer functionality, and score calculation.

The application presents multiple-choice questions to the user, records responses, and displays the final score upon completion of the quiz.

---

# 🚀 Overview

The Quiz Application is designed to provide an interactive way of conducting quizzes through a desktop-based Java program.

The project allows users to answer a series of questions within a specified time and automatically calculates the final score based on their responses.

---

# ✨ Features

## 📝 Multiple Choice Questions

* Displays a set of quiz questions
* Multiple options for each question
* User-friendly quiz flow

## ⏳ Timer Functionality

* Time limit for answering questions
* Automatic progression based on timer

## 🎯 Score Calculation

* Evaluates user responses
* Calculates total marks
* Displays final score at the end

## 🔄 Quiz Navigation

* Move through questions sequentially
* Simple and interactive interface

## 📊 Result Display

* Shows final performance
* Displays total score obtained

# ⚙️ How to Run

## 1. Clone the Repository

```bash
git clone https://github.com/VanshMirani/QuizApplication.git
```

## 2. Navigate to Project Directory

```bash
cd QuizApplication
```

## 3. Compile the Program

```bash
javac QuizApplication.java
```

## 4. Run the Program

```bash
java QuizApplication
```
